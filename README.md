## ✨ About Kuhu Crafts

Kuhu Crafts is built with an earthy, warm, Pinterest-inspired aesthetic. Every item is hand-poured, molded, and assembled in small batches using eco-conscious materials.

### Core Collections:
* 🕯️ **Handmade Soy Candles:** Formulated with premium AA+ soy wax and braided cotton wicks. Features sculpted daisy florals, sunflowers, festive modaks, and aroma tea lights.
* 🌿 **Eco-Casting Decor & Trays:** Stone-smooth, non-toxic trinket dishes, jewelry trays, coasters, animal figurines, and mini dinosaurs.
* 🎨 **Kids & Family DIY Painting Kits:** Screen-free creative activity sets featuring casted figurines bundled with non-toxic paints and brushes (ideal for birthday return gifts and hobby sessions).
